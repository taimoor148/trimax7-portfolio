# Trimax7 — Portfolio

Single-file portfolio for **Taimoor / Trimax7** — premium websites, AI-powered interfaces, and the automation systems behind them.

## What's inside

One self-contained `index.html` (~1,650 lines) with:

- **Motion** — GSAP 3.12.5 + ScrollTrigger, Lenis smooth scroll, Three.js wireframe core (CDN).
- **Sections** — preloader, floating nav + full-screen menu, hero, pinned horizontal work gallery, services, process, about, stack constellation, Upwork, CTA, footer.
- **5 live demo projects** — Glitz & Glam, Built Solid, VELOCE, Sharp & Fade, Justice Desk.
- **Accessible** — skip link, focus states, semantic HTML, reduced-motion + no-JS fallbacks.
- **Responsive** — mobile-first breakpoints (680 / 860 / 1024 / desktop).

## Deploy

Static site — deploy `index.html` to any static host (Vercel, Netlify, Cloudflare Pages).
